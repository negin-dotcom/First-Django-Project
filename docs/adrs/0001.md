<h1>ADR - 0001: Starting a Django Inventory Application.<h1>
<h1>status: Accepted - 2026/09/01</h1>

<br>
<h2>Context: <h2>
<p>We need an application for managing products and placing orders for those products. The application should provide an api that allows clients to interact with the order management system.</p>

<br>
<h2>Decision: <h2>
<p>We will use django as the backend framework and DRF to provide the api.</p>

<br>

The initial domain contains:
<ul>
    <li>Categories</li>
    <li>Products</li>
    <li>Orders</li>
    <li>Order Items</li>
</ul>


<h2>Consequences:</h2>
<h3>pros:
    <ul>
        <li>Django has built-in features for database.</li>
        <li>DRF provides tools for building RESTful apis.</li>
    </ul>

cons:
    <ul>
        <li>We become dependent to django and drf.</li>
    </ul>
</h3>
